# Changesets

Moi thay doi can phat hanh di kem mot file changeset. Tao bang:

```bash
pnpm changeset
```

Chon goi bi anh huong va muc tang version (patch/minor/major), viet mot dong mo ta.
Khi merge vao `main`, workflow Release mo PR "Version packages"; merge PR do thi goi duoc phat hanh len npm.
